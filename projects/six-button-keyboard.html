Six-button USB keyboard

An ESP32-S3 keyboard moving from a breadboard prototype to a custom KiCad PCB.

Moving to custom PCB
The build

What it is

A six-button USB keyboard based on an ESP32-S3. The prototype is moving from a breadboard to a custom PCB designed in KiCad.

Why this form

Build intent

The aim is a compact physical input device with six buttons, built from a quick prototype into a board designed for the job.

In plain terms

How it works

The six buttons connect to the ESP32-S3, which handles the inputs and sends keyboard events over USB. The custom PCB will replace the breadboard wiring.
